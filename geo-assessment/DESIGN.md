# GEO Assessment design system

## 1. Visual theme and atmosphere

这是一个纯白的研究型评测界面，质感来自比例、留白、字号对比与精确状态。首页快速建立信任，答题页只有一个当前任务，报告页具有研究编辑的信息密度。

## 2. Color palette and roles

| Token | Value | Role |
|---|---|---|
| canvas | `#FFFFFF` | 所有页面和打印背景 |
| ink | `#1D1D1F` | 标题、正文、关键数字 |
| muted | `#6E6E73` | 元数据、辅助说明 |
| hairline | `#D2D2D7` | 分隔线与表格边界 |
| soft | `#F5F5F7` | 必要的选项与表格层级 |
| accent | `#0066CC` | 主操作、链接、当前状态 |
| ink blue | `#1B365D` | 报告标题、打印强调 |
| success | `#16794B` | 正确状态 |
| danger | `#B42318` | 错误状态 |
| warning | `#946200` | 未答与警示 |

## 3. Typography rules

产品界面使用 `-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Noto Sans SC", sans-serif`。打印报告的章节标题加入 `"Songti SC", "Noto Serif CJK SC", serif`。正文不低于 16px，辅助文字不低于 12px，动态数字统一使用等宽数字。中文行高在 1.55 至 1.75 之间。

## 4. Component stylings

按钮固定 12px 圆角，默认、悬停、按下、焦点和禁用状态完整。选项行使用 14px 圆角与实色层级，选中后显示蓝色勾选控件与浅蓝背景。报告详情使用语义化 `details` 展开，打印时全部展示。

## 5. Layout principles

间距阶梯为 4、8、12、16、24、32、48、64、96px。答题页桌面题目列为 720 至 760px，题号导航 220px，整体不超过 1120px。报告首屏先给结论与行动，图表与逐题证据随后。

## 6. Depth and elevation

白底之间使用 `#F5F5F7` 实色阶差和少量 `0 1px 3px rgba(0,0,0,.10)` 层级。内容区默认无阴影，主操作与小屏固定操作栏可使用一层轻阴影。

## 7. Guardrails

1. 所有页面背景保持纯白。
2. 题干是答题页唯一的 H1。
3. 题目区宽度根据阅读长度确定，不为导航制造大面积空白。
4. 图表与 HTML 数据表读取同一服务端模型。
5. 状态色同时搭配文字、符号或数值。
6. 页面级无渐变、玻璃效果、大面积深色和装饰性卡片阵列。
7. 触控目标高度至少 44px。
8. 动画只改变透明度与位移，并尊重减少动画偏好。

## 8. Responsive behavior

1120px 收窄桌面布局，880px 把报告双列改为单列，640px 把题号导航收入抽屉。375x667 的典型题保持题干、全部选项与操作同屏。320x568 的长选项题在选择区内滚动，页面不产生水平滚动。

## 9. Agent prompt guide

* 首页：在 `#FFFFFF` 画布上创建左对齐介绍，标题 56px 、600 字重，主按钮 `#1D1D1F`、12px 圆角。
* 答题：760px 内容列与 220px 题号列，H1 30px，选项行最小 52px，主操作黑底白字。
* 报告：顶部显示总分、阶段、正确数与用时，图表网格使用 `#D2D2D7` 1px，强调系列 `#0066CC`。
* 打印：A4、纯白背景、宋体系章节标题、小于 1px 的分隔线，全部题目详情展开。
