# 安全策略

## 支持范围

安全修复优先覆盖当前 `main` 分支和最新的 `assessment-v*` Release。PHP 7.3 仅保留兼容性门禁，公开部署建议使用仍在安全维护期内的 PHP 版本。

## 私密报告漏洞

请使用 GitHub 仓库的 **Security → Advisories → Report a vulnerability** 提交漏洞。报告应包含受影响版本、复现步骤、影响范围和可行的缓解方案。

如果仓库暂未开放私密漏洞报告，可以创建一个不含漏洞细节的 Issue，请维护者提供私密联系渠道。请勿在公开 Issue、日志或截图中提交姓名、Cookie、应用密钥、数据库、服务器地址或可直接利用的攻击步骤。

维护者确认后会给出处理状态。修复发布前，请为部署者保留可执行的缓解措施和回滚路径。
