# GEO 题库 v1.2 逐题审查与优化清单

审查对象：`geo-30-v1.1`

优化题集：`geo-30-v1.2`

## 审查结论

旧题集覆盖机制、内容、实验、平台和安全，研究依据完整。用户理解成本主要来自三类问题：题干直接引用数据集比例或平台样本，未读过数据仓库的用户缺少上下文；RAG、候选集、答案吸收、Jaccard、LLM 评委等术语集中出现；海外题占一个完整维度，国内业务场景不足。

v1.2 采用以下约束：

- 地域比例固定为国内 18 题、通用 9 题、海外 3 题
- 题干使用官网、产品页、流量、平台、网页端、App、电商等日常场景
- 论文和数据继续作为解析证据，答题不要求提前读过论文或数据集
- 具体数据比例、仓库字段和统计术语退出题干
- 首次出现的 GEO、AI、App 等必要词保留，其他技术概念换成普通中文
- 每个选项都有独立说明，解析回答正确原因、错误边界和可迁移方法
- 30 题、100 分、20 道单选、10 道多选和 30 分钟上限保持不变

## 六维结构调整

|---|---|---|

| Q06 至 Q10 | 内容与证据优化 | 把用户问题、事实依据、适用条件和页面结构组织清楚 |
| Q11 至 Q15 | 测量与实验判断 | 重复测试、设置参照、保存条件并校准评分 |
| Q16 至 Q20 | 平台与来源差异 | 理解海外与国内平台、端别和来源选择差异 |
| Q21 至 Q25 | 国内平台与内容生态 | 处理官网、第三方信息、时效、标题实验和数据边界 |
| Q26 至 Q30 | 落地与风险治理 | 处理操纵、安全、图片、电商和长期维护 |

## 验收标准

- 地域统计为 `domestic=18`、`general=9`、`overseas=3`
- 54 篇论文和两套数据来源仍能从题目追溯
- 题目总预计作答时间不超过 1800 秒
- 初学者无需知道数据仓库字段、论文编号或具体样本比例即可理解题干
- 默认安装导入 v1.2，现有 v1.1 数据不会被覆盖
