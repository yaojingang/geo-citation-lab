# 题目来源与编写边界

GEO Assessment 的 30 道题是 GEO Citation Lab 原创编写的场景化测验内容。题干、选项、解析、原理和误区标签采用 CC BY 4.0。论文和来源数据只承担证据依据，各自维持原许可。

## 证据范围

题集 `geo-30-v1.2` 的证据冻结于 2026-08-04，引用 54 篇 GEO、AEO、生成式搜索、RAG、检索安全与内容优化研究，并结合两套仓库数据：

- 跨平台引用与答案吸收实验，覆盖 ChatGPT、Google AI Overview、Gemini 与 Perplexity
- CN-GEO 中文生成式搜索引用数据，原始层包含 214,119 条引用记录

完整来源清单、标题、年份、链接和每题对应的 `source_refs` 位于 [`database/seeds/geo-30-v1.2.json`](../database/seeds/geo-30-v1.2.json)。仓库的 [`02-geo-aeo-ai-search-papers/`](../../02-geo-aeo-ai-search-papers/) 提供论文导航与校验信息，测试系统 Release 不包含论文 PDF。`geo-30-v1.1` 保留为历史题集，现有报告可以继续复查。

## 编写方法

每道题从可验证的机制、实验观察或数据特征出发，再转换成日常业务场景。题干无需读者提前看过论文、数据仓库或数据集，论文和数据只承担解析证据。单选题检查一个最准确判断，多选题要求完整选择正确集合。每个选项都有独立说明，题目权重按认知层级与综合难度分配，总分固定为 100 分。

地域结构固定为 18 道国内题、9 道通用题和 3 道海外题。国内题覆盖官网内容、第三方来源、平台与端别、内容时效、电商和长期治理，海外题只保留平台差异、语言来源边界和测试方法。

题集通过 `validation_profile: beginner-domestic-v1` 启用初学者编辑规则，包括地域配额、题干长度、术语和结尾标点校验。后续题集可以显式选择高度匹配的编辑规则。`region_scope` 会保存到题目记录和作答快照，方便后续报告按地域分析。

六个诊断维度为：

1. GEO 基础理解
2. 内容与证据优化
3. 测量与实验判断
4. 平台与来源差异
5. 国内平台与内容生态
6. 落地与风险治理

## 数据结论的使用限制

数据中的相关关系不能单独证明因果。平台、模型、检索工具和时间窗口变化都会影响引用结果。`geo-30-v1.2` 把具体比例和仓库字段移出题干，相关数据只在解析和来源中说明。题目涉及观察结果时，会要求受控验证、重复测试和完整记录。

## 修订要求

修改题目时，需要同时检查题干、选项、正确集合、分值、解析、原理、误区标签、来源引用和预计用时。提交前运行：

```bash
php bin/console questions:verify
composer test
```

新来源应进入题集的 `sources` 数组并带有稳定链接。来源内容存在许可或可访问性变化时，保留书目信息并更新链接说明。
