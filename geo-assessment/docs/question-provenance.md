# 题目来源与编写边界

GEO Assessment 的 30 道题是 GEO Citation Lab 原创编写的研究型测验内容。题干、选项、解析、原理和误区标签采用 CC BY 4.0。论文和来源数据只承担证据依据，各自维持原许可。

## 证据范围

题集 `geo-30-v1.1` 冻结于 2026-08-04，引用 54 篇 GEO、AEO、生成式搜索、RAG、检索安全与内容优化研究，并结合两套仓库数据：

- 跨平台引用与答案吸收实验，覆盖 ChatGPT、Google AI Overview、Gemini 与 Perplexity
- CN-GEO 中文生成式搜索引用数据，原始层包含 214,119 条引用记录

完整来源清单、标题、年份、链接和每题对应的 `source_refs` 位于 [`database/seeds/geo-30-v1.1.json`](../database/seeds/geo-30-v1.1.json)。仓库的 [`02-geo-aeo-ai-search-papers/`](../../02-geo-aeo-ai-search-papers/) 提供论文导航与校验信息，测试系统 Release 不包含论文 PDF。

## 编写方法

每道题从可验证的机制、实验观察或数据特征出发，再转换成应用场景。单选题检查一个最准确判断，多选题要求完整选择正确集合。错误选项对应常见误区，解析同时说明正确路径和错误路径。题目权重按认知层级与综合难度分配，总分固定为 100 分。

六个诊断维度为：

1. 底层机制与范式
2. 实验设计与测量
3. 内容与优化
4. 海外引用特征
5. 国内引用特征
6. 安全、伦理与治理

## 数据结论的使用限制

数据中的相关关系不直接构成因果结论。平台、模型、检索工具和时间窗口变化都会影响引用结果。题目中涉及对比数据时，会把结论限定在对应样本和实验范围内，并优先要求验证、重复试验和结构化测量。

## 修订要求

修改题目时，需要同时检查题干、选项、正确集合、分值、解析、原理、误区标签、来源引用和预计用时。提交前运行：

```bash
php bin/console questions:verify
composer test
```

新来源应进入题集的 `sources` 数组并带有稳定链接。来源内容存在许可或可访问性变化时，保留书目信息并更新链接说明。
