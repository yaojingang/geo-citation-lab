# Changelog

本文件记录 GEO Assessment 的公开版本变化，格式参考 Keep a Changelog，版本号遵循语义化版本。

## [Unreleased]

### New Features

1. **完整能力测试**，提供 30 道题、30 分钟限时、100 分权重、十次测试机会和永久浏览器身份
2. **多维诊断报告**，提供六维能力、难度、用时、题目矩阵、历史趋势、群体分位和 30 道题详情
3. **轻量部署**，支持 PHP 7.3.5+ 与 SQLite 3.24+，Release 包包含生产依赖和 SHA-256 校验
4. **可选访问统计**，公共源码默认关闭百度统计，部署者通过环境变量启用自己的统计 ID

### Fixes & Improvements

1. **隐私与安全边界**，加入 CSRF、CSP、报告归属校验、参数化 SQL、限流、结构化日志和本人数据删除
2. **响应式答题体验**，长题目和选项在桌面与移动端保持可读，操作按钮与进度模块稳定对齐
3. **可复现发布门禁**，加入 PHP、JavaScript、PHP 7.3、题库、HTTP 冒烟和发布包隔离安装验证
